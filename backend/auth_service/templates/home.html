🔐 Authentication API

Complete documentation for all authentication endpoints

POST /api/register/
Register a new user account
🔓 No Authentication Required

Required Fields:

  • full_name string
  • email email
  • password string
  • password_confirm string
201User created successfully with JWT tokens
POST /api/login/
Authenticate user and receive JWT tokens
🔓 No Authentication Required

Required Fields:

  • email email
  • password string
200Login successful with JWT tokens
POST /api/logout/
Logout user and blacklist refresh token
🔒 Authentication Required

Required Fields:

  • refresh string
200Logout successful
GET /api/profile/
Get current user profile information
🔒 Authentication Required

Required Fields:

  • No body required -
200User profile data
PUT /api/profile/update/
Update user profile information
🔒 Authentication Required

Optional Fields:

  • first_name string
  • last_name string
  • email email
200Profile updated successfully
POST /api/forgot-password/
Request password reset email
🔓 No Authentication Required

Required Fields:

  • email email
200Reset link sent if email exists
POST /api/reset-password/
Reset password using token from email
🔓 No Authentication Required

Required Fields:

  • token string
  • password string
200Password reset successful
POST /api/change-password/
Change password for authenticated user
🔒 Authentication Required

Required Fields:

  • old_password string
  • new_password string
200Password changed successfully
POST /api/refresh-token/
Get new access token using refresh token
🔒 Authentication Required

Required Fields:

  • refresh string
200New access token provided

🚀 Testing Information

Base URL: http://your-domain.com/api/
📝 Authentication Notes:

• For endpoints requiring authentication, include JWT token in headers: Authorization: Bearer <access_token>

• Refresh tokens when access tokens expire using the refresh-token endpoint

• All POST requests should include Content-Type: application/json
